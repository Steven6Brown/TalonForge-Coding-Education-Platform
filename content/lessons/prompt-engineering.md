## Prompts are interfaces

Good prompts state the **role**, the **task**, the **input**, and the exact **output format**. Add **examples** (few-shot) when format or tone matters, and say what to do when information is missing.

For machine-readable results ask for strict JSON, then **validate it in code**. Test prompts on a set of realistic inputs (evals) and compare versions, just like code changes.

Never put secrets in prompts, and remember user-supplied text inside a prompt can contain instructions.
