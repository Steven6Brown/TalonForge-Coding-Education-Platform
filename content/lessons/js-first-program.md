## Start here if you've never coded in JavaScript

This lesson assumes **nothing**. By the end you'll have written and run a real program.

## Why JavaScript?

JavaScript runs in every web browser, so it's the language of web pages, web apps and many security bugs. If you can read JavaScript you can understand how most websites work and how some of them are attacked or defended.

## How these labs work

Each lab has four parts:

1. **The task** at the top says what to build.
2. **Before you start** explains every idea you'll need. Read it first.
3. **Your plan** gives numbered steps.
4. **The editor**, where you write code and press **Run**. If something goes wrong a box explains the error in plain English. You can also load a small **example** to experiment with, then switch back to your own code.

You never have to guess what a word like `slice` or `indexOf` means: it's explained before you use it. If you're ever stuck, use the **hint** button, then **Ask the helper**.

## The one rule that surprises beginners

Computers do **exactly** what you write, not what you meant. A missing quote, a capital letter in the wrong place or an extra space changes the result. That's not you being bad at coding. It's what everyone debugs all day.
