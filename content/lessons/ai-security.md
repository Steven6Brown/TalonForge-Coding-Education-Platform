## New tech, familiar problems

- **Prompt injection:** untrusted text (emails, web pages, documents) carries instructions the model may follow.
- **Excessive agency:** an AI agent with broad tools can be tricked into harmful actions. Give it least privilege and require human approval for risky steps.
- **Insecure output handling:** using model output in SQL, shell or HTML without validation.
- **Data leakage:** secrets or private data placed in prompts can be exposed. Keep keys server-side.

Prompts are not security boundaries. Enforce permissions in code.
