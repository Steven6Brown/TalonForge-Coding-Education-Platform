## The map

- **AI**: the broad goal of machines doing tasks that seem intelligent.
- **Machine learning (ML)**: systems that learn patterns from data instead of hand-written rules.
- **Deep learning**: ML with many-layered neural networks.
- **LLM (large language model)**: a neural network trained to predict the next token of text, which makes it good at writing, summarizing and coding.

## Key ideas

- **Training** fits the model to data; **inference** uses it. Most developers only do inference through an API.
- **Tokens** are text pieces; context windows, speed and price are measured in them.
- **Hallucination:** fluent but wrong output. Verify anything that matters.
